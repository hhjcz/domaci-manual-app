# Electrical panel

The panel is in the hallway, behind the white door next to the coat rack.

## Breaker layout

| Row | Breaker | Serves                      |
| --- | ------- | --------------------------- |
| 1   | F1      | Main switch                 |
| 1   | F2      | RCD, whole house            |
| 2   | F3      | Kitchen sockets             |
| 2   | F4      | Oven                        |
| 3   | F5      | Lighting, ground floor      |
| 3   | F6      | Technical room, heat pump   |

## After a trip

Switch everything off, then the main switch on, then one breaker at a time to
find the faulty circuit.
