# Network

## Router

The router is in the technical room on the shelf. Reboot by unplugging the
power for ten seconds.

## Wi-Fi

- `Home` — everyday devices.
- `Home-IoT` — smart-home devices, isolated from `Home`.

## Home Assistant

Runs on the small box next to the router. If the dashboard is unreachable,
check the router first; Home Assistant itself almost never needs a restart.
